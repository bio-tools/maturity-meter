# Usage

Automated maturity model for research software tools

## Installation

Install from a source checkout:

```bash
poetry install
```

## Run the software

```bash
poetry run python -m maturity_meter
```

## Available functions

See [Functions and operations](functions.md) for supported operations, inputs, outputs, and command examples.

## Access interfaces

- Command-line tool (Stable)
- Library (Stable)
- Web API

## Platform support

- Platform independent - Officially supported

## Entry points

```bash
poetry run maturity-meter evaluate
poetry run maturity-meter-serve
```
