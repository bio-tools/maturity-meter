# Maturity meter

Automated maturity model for research software tools

This project develops an automated maturity model for research software tools
hosted on GitHub or GitLab. It assesses signals such as documentation quality,
FAIR compliance, maintenance, and reuse, as a scalable complement to manual
maturity annotation. Long term, the maturity level will help researchers
compare and select tools in the Research Software Ecosystem.
